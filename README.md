## 🔬 Study Method

각 주제는 가능한 한 다음 과정을 기준으로 기록합니다.

```text
Concept
   ↓
Theory
   ↓
Implementation
   ↓
Experiment
   ↓
Result
```

### Concept
공부하려는 개념과 목적

### Theory
개념의 동작 원리와 이론

### Implementation
직접 작성한 코드와 구현

### Experiment
조건을 변경하거나 여러 구현 방법을 비교

### Result
성능, 장단점, 문제점 및 배운 점 정리

## 🎯 Goals

이 저장소의 목표는 단순한 코드 보관이 아니라,

- 여러 구현 방법의 성능 비교하기
- 최적화 과정과 결과 기록하기

입니다.
